# Pemrograman Berbasis Objek

Repository ini berisi source code praktikum dan tugas mata kuliah **Pemrograman Berbasis Objek (PBO)**.

## Informasi Mata Kuliah

- **Mata Kuliah:** Pemrograman Berbasis Objek
- **Program Studi:** D4 Teknik Informatika
- **Jurusan:** Teknologi Informasi
- **Perguruan Tinggi:** Politeknik Negeri Malang
- **Semester:** 3
- **Bahasa Pemrograman:** Java

## Deskripsi

Repository ini digunakan sebagai dokumentasi dan tempat penyimpanan source code selama kegiatan praktikum mata kuliah **Pemrograman Berbasis Objek**.

Source code dikelompokkan berdasarkan **jobsheet/pertemuan**. Setiap jobsheet dapat berisi source code praktikum dan tugas yang diberikan.

## Keterangan

| Folder/File | Keterangan |
|-------------|------------|
| `P1/` | Berisi source code Jobsheet 1. |
| `P1/BikeDemo/` | Berisi source code praktikum mengenai implementasi class dan object menggunakan Java. |
| `P1/Tugas/` | Berisi source code tugas pada Jobsheet 1. |
| `OOP.java` | Program untuk mempelajari konsep dasar Object-Oriented Programming. |
| `Procedural.java` | Program sebagai perbandingan antara pemrograman prosedural dan pemrograman berorientasi objek. |
| `.gitignore` | Berisi file atau folder yang tidak perlu diunggah ke repository. |
| `README.md` | Dokumentasi repository. |
